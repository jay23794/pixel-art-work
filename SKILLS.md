# Skills

Project skills live in `.claude/skills/`. Use them in this order of preference.

| skill | when |
|---|---|
| **`night-artist`** | **Use first for any night scene** (new scene, night variant, night light or weather effect). Workflow, kit reference, recipes, moods and rules for the night kit in `art/lib/`. |
| `pxl-pixel-art` | The pxl DSL itself (sprites, scenes, anims, build, ascii). Every art/ study uses it. |
| `pixel-art` | Critique and craft: palettes, dithering, clusters, outlines, animation habits. Use for the critique step. |
| `pixelfx` | Reference for effect techniques (MIT). Borrow ideas, not code: it paints with alpha and additive light. |
